# MiniOrder

架空のカフェ向けモバイルオーダーシステムです。

## アプリの目的

お客様がスマートフォンから商品を注文し、店舗スタッフが注文の受付・調理・提供状況を一元管理できる仕組みを構築します。

注文待ち時間の削減、店舗業務の効率化、顧客体験の向上を目指します。

## 使用技術（予定）

- TypeScript
- Node.js / Fastify
- PostgreSQL
- Docker
- AWS
- GitHub Actions

## 実装予定の機能

- [ ] 商品一覧の取得
- [ ] 注文の作成
- [ ] 注文番号の発行
- [ ] 注文状況の取得
- [ ] 注文ステータスの更新
- [ ] データベースへの保存
- [ ] 自動テスト
